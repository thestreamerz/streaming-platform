## 🔄 Maintenance

### **If Servers Go Down:**

1. Check which servers are affected
2. Open `src/services/enhancedStreaming.ts`
3. Set `active: false` for dead servers
4. Add new working servers if found
5. Run: `npm run build`
6. Run: `firebase deploy --only hosting`

### **Adding New Servers:**

```javascript
{
  id: 'new-server',
  name: 'New Server Name',
  quality: 'HD',
  type: 'primary',
  baseUrl: 'https://newserver.com/embed',
  active: true,
  priority: 9,
  category: 'streaming',
  features: ['HD Quality', 'Fast Loading']
}
```

### **Testing New Servers:**

1. Add server to array
2. Test with known TMDB IDs:
   - Movie: 550 (Fight Club)
   - TV: 1396/1/1 (Breaking Bad S01E01)
3. Verify video loads and plays
4. If works, set active: true and deploy
