# STREAMERZ

Ultimate Movie & TV Streaming Platform

## Features

- 🎬 **Premium Streaming**: Access to thousands of movies and TV shows
- 🚀 **Multiple APIs**: 9 integrated streaming sources for maximum availability
- 📱 **Responsive Design**: Works perfectly on all devices
- 🔍 **Advanced Search**: Find content with powerful filtering options
- 🎯 **Personalized**: AI-powered recommendations based on your preferences
- 📊 **Analytics**: Track your viewing habits and preferences
- 🔴 **Live TV**: Access to live television channels
- 🤖 **AI Assistant**: Get help finding content with SZ AI

## Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Backend**: Firebase (Firestore, Auth, Hosting)
- **APIs**: TMDB, Multiple Streaming Sources
- **PWA**: Progressive Web App capabilities

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/streamerz.git
   cd streamerz
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Firebase**
   - Create a Firebase project
   - Enable Firestore, Authentication, and Hosting
   - Add your Firebase config to `src/firebase/config.ts`

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Build for production**
   ```bash
   npm run build
   ```

## Deployment

Deploy to Firebase Hosting:

```bash
npm run build
firebase deploy --only hosting
```

## Streaming APIs

The platform integrates with 9 premium streaming APIs:

1. **VidLink Pro** - Primary 4K streaming source
2. **WatchUg.to** - Reliable movie and TV content
3. **111Movies** - Popular streaming alternative
4. **VidFast Pro** - Fast streaming with multiple qualities
5. **RiveStream** - High-quality streaming service
6. **VideoEasy** - Easy-to-use streaming platform
7. **MappleTV** - Premium streaming content
8. **PStream** - Professional streaming service
9. **Vidora** - Comprehensive streaming library
